# Universal Support Theorems for Resilient Coverage

**Deep Bhattacharjee*** · **Ushashi Bhattacharya** · **Sanjeevan Singha Roy**

*First and corresponding author: itsdeep@live.com.*

This is one complete Hexagon preparation package for a standalone analytical paper. It is not labeled as a v3 manuscript.

1. Read **UniversalSupportTheoremsForResilientCoverage.pdf**.
2. Upload **UniversalSupportTheoremsForResilientCoveragetex.zip** to Overleaf or Hexagon. The main file is **main.tex** at its root. For a first local build run `pdflatex main.tex` until references and contents stabilize (normally three passes).
3. Copy the fields from **hexagonsubmissionform.md** and provide **aiprovenance.md** in the provenance area where supported.

The user-declared selections are **all parts checked and understood by a human** and **a mix of human-written and AI-generated text**. Funding, competing-interest and ethics statements are in **DECLARATIONS.md** and the paper.

The source ZIP contains only the reachable manuscript sources and required figures. It contains one paper, no obsolete version, no external embedded article and no compilation debris. Optional programs and controls are separate in **supplementary/**. Their results are not proof premises.

The main contribution is a support theorem for monotone selectors with a common convex part. Its geometric consequences include exact thresholds and a complete resilience frontier. Novelty and significance should be judged against the cited literature; no journal acceptance is guaranteed.

The related DOI **10.5281/zenodo.23731783** is cited as requested. It identifies a companion archive. This package does not claim a new Zenodo DOI or a new Hexagon identifier.
